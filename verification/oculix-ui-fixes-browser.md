# UI fixes browser smoke

نسخة production على المنفذ 3012 أظهرت زر «تثبيت» بشكل واضح في الصفحة، كما ظهر شريط الزمن بعد الإصلاح مع تسمية عربية «الزمن» وزر «الآن». فُتحت الإعدادات بنجاح، وظهرت شبكة اللغات والثيمات والخلفيات.

سيتم استخدام تفاعل مستقل لاحقاً لتغيير اللغة والخلفية والتحقق من الترجمة الفعلية وتطبيق الخلفية.

في نسخة production على المنفذ 3012 ظهر زر «تثبيت». بعد اختيار Español تحولت إعدادات Oculix والثيمات والخلفيات وأسماء أقسام مساحة العمل وشريط عدسة الاستخبارات إلى الإسبانية، كما تحول زر التثبيت إلى «Instalar». بقيت بعض التسميات العامة القديمة في البطاقات/الشريط الجانبي بالإنجليزية، لذلك سيجري توسيع قاموس LocaleSurface لهذه العبارات الثابتة دون ترجمة payloads الحية.
